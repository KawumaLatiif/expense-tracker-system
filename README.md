# Expense Tracker System

A modular personal expense management application built with Python, SQLite, Django, and React.

## Project Objectives

- Record and categorize expenses.
- View, search, update, and delete expense records.
- Generate spending summaries and reports.
- Provide a web interface for managing personal finances.
- Expose expense-management functionality through a REST API.
- Apply automated testing, version control, and maintainable software design.

## Technology Stack

- **Backend:** Python, Django, Django REST Framework
- **Database:** SQLite during development
- **Frontend:** React
- **Version Control:** Git and GitHub
- **Testing:** Python unittest and Django testing tools
